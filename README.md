## 📊 Featured Project

### Global Electronics Retailer Sales Analysis

End-to-end sales analysis using **Python, Pandas, Matplotlib, Power BI, and DAX**.

The project covers:

- Data cleaning and transformation
- Exploratory Data Analysis
- Revenue and sales KPIs
- Product and geographic analysis
- Sales channel comparison
- Seasonality analysis
- Interactive Power BI dashboard

**Key results:** $55.76M in analyzed revenue, 26.33K orders, and 197.76K units sold.

🔗 [View the project](https://github.com/ChaPepperDev/global-electronics-sales-analysis)
